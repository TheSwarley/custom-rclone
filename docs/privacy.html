Privacy Policy

Last updated: November 18, 2026

This policy describes how custom-rclone (“the app”) handles information. The app is a private configuration of the open-source rclone tool, used only by its developer and a small number of invited users.

Information the app accesses

When you authorize the app with your Google account, rclone receives an OAuth access token and refresh token. These let it read, create, modify and delete files in your Google Drive, limited to the permissions (scopes) you approve on Google's consent screen.

How the information is used

Google user data is used only to perform the file operations you run yourself with rclone on your own computer (for example listing, uploading, downloading, syncing or deleting files). It is not used for any other purpose.

Storage

OAuth tokens are stored only on your own device, in your local rclone configuration file. The app has no server or database. File contents and metadata travel directly between your computer and Google's servers. They are never sent to, stored by, or visible to the developer.

Sharing

Google user data is not sold, shared with, or transferred to any third party. It is not used for advertising, and it is not used to develop, improve or train AI or machine-learning models.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

You can revoke the app's access at any time at myaccount.google.com/permissions. To remove locally stored tokens, delete the corresponding remote from your rclone configuration (rclone config delete <remote>) or delete the configuration file.

Changes

This policy may be updated from time to time. Changes will be published on this page with a new “Last updated” date.

Contact

Questions about this policy can be raised via the project's GitHub repository.
