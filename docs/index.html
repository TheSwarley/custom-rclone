custom-rclone

custom-rclone is a private, non-commercial setup of the open-source rclone command-line tool. A small number of invited people use it to sync and back up files in their own Google Drive accounts.

What it does

The app uses Google OAuth so that rclone, running on the user's own computer, can access that user's Google Drive on their behalf. It is not a hosted service: there is no server, no website login, and no data is sent to the app's developer.

Who can use it

The app is for personal use only by its developer and invited users. It is not offered to the public.
