# custom-rclone

Static GitHub Pages site with the home page, privacy policy and terms of service
that the Google OAuth consent screen requires for a private rclone client.

The site files are in [`docs/`](docs/). Published URLs:

| Page | URL |
| --- | --- |
| Home | https://theswarley.github.io/custom-rclone/ |
| Privacy Policy | https://theswarley.github.io/custom-rclone/privacy.html |
| Terms of Service | https://theswarley.github.io/custom-rclone/terms.html |

## Enabling GitHub Pages

In the repository, go to **Settings → Pages → Build and deployment**. Set Source to
*Deploy from a branch*, Branch to `main` and the folder to `/docs`.
